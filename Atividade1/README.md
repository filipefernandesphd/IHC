# Atividade 1

40 participantes realizaram uma avaliação de usabilidade de um aplicativo de mensagens. Seu objetivo é realizar uma análise quanto à usabilidade do aplicativo. 

Arquivos:
- `lista_tarefas.csv`: contém as listas realizadas pelos usuários
- `sus_terefas.csv`: contém o tempo em segundos de cada participante
- `sus_respostas.csv`: contém as respostas dos participantes
